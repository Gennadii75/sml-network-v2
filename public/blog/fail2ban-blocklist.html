Сервер без Cloudflare: blocklist + fail2ban + iptables

Общая база blocklist.txt — обычный текст, один IP на строку. Ее ест любой Linux.

Вариант A: ipset, обновление по крону

# раз в 15 минут
curl -s https://gennadii75.github.io/sml-network-v2/blocklist.txt -o /tmp/sml.txt
ipset create sml-block hash:net -exist
ipset flush sml-block
while read ip; do ipset add sml-block "$ip" -exist; done < /tmp/sml.txt
iptables -I INPUT -m set --match-set sml-block src -j DROP

Вариант B: fail2ban под свои логи

Оставьте fail2ban ловить сканеры (404-пачки, перебор wp-login) как раньше, а blocklist держите вторым рубежом через ipset выше. Не скармливайте fail2ban весь blocklist как jail — тысячи IP в одном jail тормозят перезапуск.

Важно

База обновляется каждые ~15 минут. Не баньте подсети целиком — только точные IP. Выход из бана: IP исчезает из активной выборки, при следующем обновлении ipset его не будет.
