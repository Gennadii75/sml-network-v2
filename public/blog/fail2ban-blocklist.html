Сервер без Cloudflare: blocklist + fail2ban + iptables

Общая база blocklist.txt — текст, один IP на строку. Ее ест любой Linux.

Вариант A: ipset, обновление по крону

# раз в 15 минут
curl -s https://gennadii75.github.io/sml-network-v2/blocklist.txt -o /tmp/sml.txt
ipset create sml-block hash:net -exist
ipset flush sml-block
while read ip; do ipset add sml-block "$ip" -exist; done < /tmp/sml.txt
iptables -I INPUT -m set --match-set sml-block src -j DROP

Вариант B: fail2ban под свои логи

Пусть fail2ban ловит сканеры (404-пачки, перебор wp-login) как раньше, а blocklist держите вторым рубежом через ipset выше. Не скармливайте весь blocklist в один jail — тысячи IP тормозят перезапуск.

Важно

База обновляется каждые ~15 минут. Не баньте подсети целиком — только точные IP. Хотите еще и зарабатывать, а не только блокировать — подключите воркер.
