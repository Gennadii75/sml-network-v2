Ложные срабатывания: не заблокируй живых

Главное: наш воркер никого не блокирует

Клиентский скрипт делает только одно — при высоком скоре шлет репорт на sementsul.net/api/report-bot и пропускает запрос дальше (return fetch(request)). Живой посетитель ничего не заметит даже при ложном скоре: ни капч, ни 403.

А если режете по blocklist на своем сервере?

  • Не применяйте базу к белым ботам: Googlebot, Bingbot проверяйте обратным DNS, а не IP.
  • Начните с режима «только лог»: неделю пишите совпадения, потом включайте DROP.
  • Следите за метриками воркера: Observability → Workers Logs покажет все репорты.
  • Тестовый параметр ?bot_trigger=1 — только для проверки связи, не для бана себя.
