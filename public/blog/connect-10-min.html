Подключение сайта к SML за 10 минут

Нужно: домен на Cloudflare (хватит free-тарифа) и адрес BNB-кошелька.

Шаг 1. Сгенерируй скрипт

Открой генератор, вставь адрес кошелька 0x..., скопируй код.

Шаг 2. Создай Worker

Compute → Workers → Create → имя вида мой-домен-guard → Deploy → Edit code → вставь скрипт → Deploy.

Шаг 3. Секрет и роут

Settings → Variables and Secrets → Secret SHARED_SECRET (выдает оракул сети). Domains → Add → Route твой-домен/*. Redeploy.

Шаг 4. Проверка

https://твой-домен/?bot_trigger=1

Открой этот URL — воркер отправит тестовый репорт. Сайт работает как раньше (трафик идет транзитом). Первый боевой минт — после первой реальной атаки, обычно 15–30 минут: D1 → оракул → контракт → твой кошелек.
