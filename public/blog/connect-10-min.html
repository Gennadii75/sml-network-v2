Connecting your site to SML in 10 minutes

You need: a domain on Cloudflare (the free plan is enough) and a BNB wallet address.

Step 1. Generate the script

Open the 10-minute setup, paste a 0x… wallet address, copy the code.

Step 2. Create the Worker

Compute → Workers → Create → a name like my-domain-guard → Deploy → Edit code → paste the script → Deploy.

Step 3. Secret and route

The personal secret comes from the connect page (step 2) — paste it as is. Domains → Add → route your-domain/*. Redeploy.

Step 4. Verify

https://your-domain/?bot_trigger=1

Open this URL — the worker will send a test report. The site keeps working as before (traffic passes through). The first live mint comes after the first real bot attack, usually within 15–30 minutes: D1 → oracle → contract → your wallet.
