Подключение сайта к SML за 10 минут

Нужны: домен на Cloudflare (любой тариф, хоть free) и адрес BNB-кошелька.

Шаг 1. Сгенерируй скрипт

Открой cloudflare-connect.html, вставь адрес кошелька 0x..., скопируй код.

Шаг 2. Создай Worker

Compute → Workers → Create → имя вида мой-домен-guard → Deploy → Edit code → вставь скрипт → Deploy.

Шаг 3. Секрет и роут

Settings → Variables and Secrets → Secret SHARED_SECRET (выдает оракул сети). Domains → Add → Route твой-домен/*. Redeploy.

Шаг 4. Проверка

https://твой-домен/?bot_trigger=1

Открой этот URL — воркер отправит тестовый репорт. Убедись, что сайт работает как раньше (воркер пропускает весь трафик транзитом). Первый боевой минт придет после первой реальной атаки бота, обычно в пределах 15–30 минут: D1 → оракул → контракт → твой кошелек.
