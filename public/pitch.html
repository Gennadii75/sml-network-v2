05 · Технологии

Ноль серверов

  • Cloudflare Workers + D1 — исполнение и база на краю сети. Нечего DDoSить, нечего блокировать.
  • GitHub Actions + Pages — оракул и витрина. Хостинг — $0.
  • BNB Chain — дешевый газ для частых минтов.
  • Воркер никого не блокирует — только учет. Ноль риска для живых посетителей.
